# curion

[English](README.md)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

ターミナルで遊ぶSFコレクションゲーム — GUIDから生成される「興味を司る粒子」を集めよう。

## なぜ curion?

バーコードバトラーを覚えていますか? 適当なバーコードをスキャンすると、予測できないステータスの
キャラクターが生まれる。Curionはその興奮をターミナルに持ち込みます。バーコードの代わりにGUIDを、
戦士の代わりに「キュリオン」を — あらゆる名詞を象徴する架空の粒子を集めます。

猫、超新星、藍色、正義の概念 — すべてがキュリオンとして出現を待っています。30秒ごとに新しい
GUIDが発行され、ハッシュが計算され、何かがコレクションに加わります。何が出るかは制御できません。
ただ眺めて、組み合わせて、次のレジェンダリーを追いかけるだけ。

Cookie Clicker のロジックを、80x24のターミナルで動くガチャに適用したようなもの。
広告なし、課金なし、ネット接続不要。ただ、もう1回。

## 特徴

- **GUID ベースの決定論的生成** — 各GUIDはSHA-256ハッシュで特定のキュリオンに変換。同じGUIDからは常に同じ結果
- **268の収集対象名詞** を9カテゴリに分類（動物、植物、色、物体、概念、元素、食べ物、現象、抽象）
- **4段階レアリティ** — コモン（60%）、レア（30%）、エピック（9%）、レジェンダリー（1%）
- **合成システム** — 2つのキュリオンを組み合わせて新しいものを生成。15のレシピ（水+火=蒸気、夢+光=希望、...）
- **39の実績** — マイルストーン、レアリティハント、カテゴリコンプリート、連続ログイン、プレイ時間目標、特殊チャレンジ
- **5タブ TUI**（ratatui製）— ダッシュボード、コレクション、実績、統計、合成
- **3層ナビゲーション** — タブバー + 左ペインの中項目 + 右ペインの内容表示。将来のPWA情報設計と一致
- **先行レイアウト実装** — ログインボーナス / デイリーミッション / 時系列は専用Issue前の骨組みとして先に枠を用意
- **Nostr ID** — 将来の分散型トレードに向けて、各プレイヤーに鍵ペアを発行
- **自動セーブ**（60秒ごと）、`s` で手動セーブ
- シングルバイナリ、ランタイム依存なし

## 仕組み

```
GUID 発行（30秒ごと）
    |
    v
SHA-256 ハッシュ
    |
    +--> カテゴリ（9種類）
    +--> 名詞（268語）
    +--> レアリティ（コモン / レア / エピック / レジェンダリー）
    +--> 属性値（興味度、希少性、美しさ）
    |
    v
キュリオンがコレクションに追加
    |
    +--> 実績チェック
    +--> 材料が揃えば合成が解禁
```

`Space` キーを押すと、タイマーを待たずにGUIDを即座に消費できます。

### キーバインド

| キー | 操作 |
|---|---|
| `1`-`5` | タブ切り替え（ダッシュボード / コレクション / 実績 / 統計 / 合成） |
| `Tab` | 次のタブ |
| `Space` | キュリオンを即座に生成（現在のGUIDを消費） |
| `j` / `k` | 左ペインの中項目を移動 |
| `↑` / `↓` | 右ペイン内の選択・スクロール |
| `Enter` | 実績報酬の受け取り / 合成の材料選択 |
| `Esc` | 合成選択のキャンセル / 終了 |
| `s` | 手動セーブ |
| `q` | 終了 |

## 合成

コレクションから2つのキュリオンを選んで組み合わせます。レシピに合致すれば新しいキュリオンが
生成され、材料は消費されます。

| レシピ | 材料 | 結果 |
|---|---|---|
| 蒸気 | 水 + 火 | 蒸気 |
| 泥 | 土 + 水 | 泥 |
| 溶岩 | 火 + 土 | 溶岩 |
| ... | ... | ... |

全15レシピ。直感系、概念系、生物系、料理系、抽象系、ごった煮系の6タイプ。
実験して発見してください。
