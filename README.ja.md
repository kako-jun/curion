# curion

[English](README.md)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

ターミナルで遊ぶSFコレクションゲーム — GUIDから生成される「興味を司る粒子」を集めよう。

## なぜ curion?

バーコードバトラーを覚えていますか? 適当なバーコードをスキャンすると、予測できないステータスの
キャラクターが生まれる。Curionはその興奮をターミナルに持ち込みます。バーコードの代わりにGUIDを、
戦士の代わりに「キュリオン」を — あらゆる名詞を象徴する架空の粒子を集めます。

猫、超新星、藍色、正義の概念 — すべてがキュリオンとして出現を待っています。30秒ごとに新しい
GUIDが発行され、ハッシュが計算され、何かがコレクションに加わります。何が出るかは制御できません。
ただ眺めて、組み合わせて、次のレジェンダリーを追いかけるだけ。

Cookie Clicker のロジックを、80x24のターミナルで動くガチャに適用したようなもの。
広告なし、課金なし、ネット接続不要。ただ、もう1回。

## 特徴

### 基本

- **GUID ベースの決定論的生成** — 各GUIDはSHA-256ハッシュで特定のキュリオンに変換。同じGUIDからは常に同じ結果
- **268の収集対象名詞** を9カテゴリに分類（動物、植物、色、物体、概念、元素、食べ物、現象、抽象）。全名詞にSFフレーバーテキスト付き（#22）
- **4段階レアリティ** — コモン、レア、エピック、レジェンダリー
- **5タブ TUI**（ratatui製）— ダッシュボード、コレクション、実績、統計、合成
- **3層ナビゲーション** — タブバー + 左ペインの中項目 + 右ペインの内容表示。将来のPWA情報設計と一致
- **Nostr ID** — 将来の分散型トレードに向けて、各プレイヤーに鍵ペアを発行
- **自動セーブ**（60秒ごと）、`s` で手動セーブ
- シングルバイナリ、ランタイム依存なし

### ダッシュボード

- **デイリーログインボーナス** — その日の初回起動で連続日数に応じた報酬を自動付与。Day 3 / 5 / 7 では保証チケットも付与
- **デイリーミッション (#20)** — 日付シードで 4 テンプレから 3 本を抽選。達成時に XP 自動付与、ローカル日付 0:00 でリセット
- **レア出現クールダウン LineGauge (#25)** — 4 時間で満タン。フル時に Rare+ 出現確率を最大 +0.3 ブースト
- **コンボカウンタ (#21)** — Rare+ の連続収集で XP 倍率がエスカレート (1.5x → 2.0x → 3.0x)。コンボ 5 で称号「コンボマスター」
- **リアルタイム出現確率表示 (#28)** — cooldown を反映した現在のレアリティ別確率を 1 行表示
- **次マイルストーン提示 (#32)** — 未達成の XP / 実績 / 連続ログインから最も近いゴールを 1 つ抽出して表示
- **SAN ゲージ (#29)** — レア獲得で増え、時間で減衰。状態別カラー、30 未満で `⚠ 異常状態` ラベル
- **寿命警告 (#30)** — 残り 1 日以下のキュリオン数を Dashboard に常時表示
- **進化進捗 (#36)** — 「あと少し感」順で上位 3 系列をダッシュボードに表示
- **装備中キュリオンサマリ (#38)** — 装備中の Curion と派生効果を 1 行で表示

### コレクション

- **所持一覧 (フレーバー + 入手履歴, #22 / #27)** — 詳細ペインにフレーバー文と `通算 N回目の収集`
- **図鑑 (#18)** — 全カテゴリの全名詞を表示。未入手は `？？？`、カテゴリ別進捗付き
- **正規表現フィルタ (#31)** — `/` で名詞 / display name / レアリティ / カテゴリにライブ検索
- **キュリオン別寿命表示 (#30)** — 各行右端に `残 N 日`（赤 / 黄 / 灰）
- **装備機能 (#38)** — `e` キーで現在フォーカス中のキュリオンを装備。Phase 1 は XP 倍率と SAN 減衰倍率に即適用

### 統計

- **レアリティ / カテゴリ BarChart** — DESIGN 準拠のレアリティ別カラーパレット
- **デイリー Sparkline** — 直近 30 日の獲得数 (#26)
- **直近獲得 Sparkline** — 16 バケットの短いウィンドウでペースを一目で把握

### 合成

- **17 種類のレシピ** — 基本 15 種 + 高リスク 2 種 (recipe_016 禁断の神 / recipe_017 黒い太陽)。詳細は `data/recipes/basic_recipes.json` を参照
- **SAFE / RISKY バッジ + 成功率ゲージ (#28 / #35)** — 各レシピ行に 10-cell バーで現在の成功確率を表示
- **公開 / 部分公開 / 未公開レシピ (#37)** — 高レアレシピは発見前は段階的にマスクされる
- **高リスク失敗モード (#35)** — レシピごとに `NoLoss` / `LoseAll` / `Salvage` を設定。失敗時は専用トーストで通知

### 実績

- **きりの悪いしきい値 (#32)** — 収集数 / 連続ログイン / プレイ時間のマイルストーンは意図的に半端な数 (27 / 47 / 103 等) を採用し「あと少し」を維持
- **達成可能 / 進行中 / 達成済み タブ** — 受け取り可能な報酬は `Enter` 1 キーで請求できる位置に常時表示

## 仕組み

```
GUID 発行（30秒ごと）
    |
    v
SHA-256 ハッシュ
    |
    +--> カテゴリ（9種類）
    +--> 名詞（268語）
    +--> レアリティ（コモン / レア / エピック / レジェンダリー）
    +--> 属性値（興味度、希少性、美しさ）
    |
    v
キュリオンがコレクションに追加
    |
    +--> 実績チェック
    +--> 材料が揃えば合成が解禁
```

`Space` キーを押すと、タイマーを待たずにGUIDを即座に消費できます。

### キーバインド

| キー | 操作 |
|---|---|
| `1`-`5` | タブ切り替え（ダッシュボード / コレクション / 実績 / 統計 / 合成） |
| `Tab` | 次のタブ |
| `Space` | キュリオンを即座に生成（現在のGUIDを消費） |
| `j` / `k` | 左ペインの中項目を移動 |
| `↑` / `↓` | 右ペイン内の選択・スクロール |
| `Enter` | 実績報酬の受け取り / 合成の材料選択 |
| `Esc` | 合成選択のキャンセル / 終了 |
| `s` | 手動セーブ |
| `q` | 終了 |

## 合成

コレクションから2つのキュリオンを選んで組み合わせます。レシピに合致すれば新しいキュリオンが
生成され、材料は消費されます。

| レシピ | 材料 | 結果 |
|---|---|---|
| 蒸気 | 水 + 火 | 蒸気 |
| 泥 | 土 + 水 | 泥 |
| 溶岩 | 火 + 土 | 溶岩 |
| ... | ... | ... |

全 17 レシピ（基本 15 種 + 高リスク 2 種: `recipe_016` 禁断の神 / `recipe_017` 黒い太陽）。
直感系・概念系・生物系・料理系・抽象系・ごった煮系・高位レジェンダリー系をカバー。
全リストは `data/recipes/basic_recipes.json` を参照。実験して発見してください。
