# Curion

> 「興味を司る粒子」を集めるSFコレクションゲーム

## 概要

**Curion**（旧名：中毒/ホリック）は、時間経過で発行されるGUIDから、バーコードバトラー的にキュリオン（粒子）を生成して集めるターミナルベースのコレクションゲームです。

「この世の全ての名詞」（魚、色、物体など）をモデルとしたキュリオンを収集し、実績を解除していきます。

## 特徴

- 🎲 **GUID生成システム**: 一定時間で新しいGUIDが発行
- 🔮 **キュリオン生成**: バーコードバトラー的なアルゴリズムで、GUIDから様々なキュリオンを生成
- 📦 **コレクション**: 魚、色、物体など、あらゆる名詞をコレクション
- 🏆 **実績システム**: 「色を10個集めた」などのアチーブメント
- 💎 **美しいTUI**: Rust製の綺麗なターミナルUI（プログレスバー、カラフルな表示）

## 技術スタック

- **Rust** - 高速で安全な実装
- **ratatui** - 美しいTUI
- **SQLite/JSON** - データ永続化
