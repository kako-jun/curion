# Curion TUI デザイン仕様

## コンセプト

**「情報過多による中毒性」**
- クッキークリッカー的な「あと少し」感の演出
- 画面の下半分を占める進捗・煽り情報
- Zellij風のタブ切り替えで複数ビューを実現
- 常に複数の目標が見えることで退屈させない

## 煽り要素の詳細設計

### 進捗表示の優先度アルゴリズム

画面下半分には、以下の優先度で「もうすぐ達成」を表示：

1. **達成率95%以上** - 🔥緊急マーク、赤色強調
2. **達成率80-94%** - ⭐マーク、黄色強調
3. **達成率50-79%** - 📦マーク、通常色
4. **達成率30-49%** - 灰色
5. **達成率30%未満** - 非表示（情報過多を避ける）

### 煽り文言パターン

```
- 「緊急！ あとXXで...」 (95%以上)
- 「もうすぐ！ あとXXで...」 (80-94%)
- 「あとXXで...」 (50-79%)
- 「目標: XXを達成」 (30-49%)
```

### プログレスバーの色分け

## 実績システム

### 実績カテゴリ

1. **収集系**
   - 総数マイルストーン: 10, 50, 100, 250, 500, 1000個
   - レアリティ別: 各レアリティで 10, 50, 100個
   - カテゴリ別コンプリート: 各カテゴリ全種類

2. **継続系**
   - 連続ログイン: 3, 7, 14, 30, 100日
   - プレイ時間: 1h, 10h, 50h, 100h, 500h

3. **特殊系**
   - 「黄金狂」: 金のキュリオンを10個
   - 「龍の化身」: 龍のキュリオンを5個
   - 「完璧主義者」: 全カテゴリコンプリート
   - 「伝説のコレクター」: Legendary 100個

4. **コンボ系**
   - 「ラッキーストリーク」: 連続3回でRare以上
   - 「ゴールデンアワー」: 1時間で10個獲得

### レベルシステム

```
経験値獲得:
- キュリオン獲得: 10 XP (Common), 25 XP (Rare), 50 XP (Epic), 200 XP (Legendary)
- 実績解除: 実績ごとに設定された報酬XP
- ログインボーナス: 50 XP/日

レベルアップ必要XP:
- Level 1→2: 100 XP
- Level 2→3: 200 XP
- Level N→N+1: N * 100 XP
```

## キー操作

```
グローバル:
- Tab / 1-4:     タブ切り替え
- q / Esc:       終了
- ?: ヘルプ

Dashboard:
- Space:         手動でGUID生成（クールダウンあり）
- r:             画面リフレッシュ

Collection:
- ↑/↓ or j/k:   スクロール
- Enter:         詳細表示
- f:             フィルター設定
- s:             ソート変更

Achievements:
- ↑/↓ or j/k:   スクロール
- Enter:         報酬受け取り（達成済み実績のみ）
```

## アニメーション

- GUID生成時: キュリオンがフェードイン
- レベルアップ: 画面全体が一瞬光る
- 実績解除: 🎉エフェクト
- Legendary獲得: 虹色のエフェクト
