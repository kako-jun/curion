# 名詞データベース

## 概要

キュリオン生成に使用する名詞のデータベースです。
全ての名詞はカテゴリ別のJSONファイルに格納されています。

## ディレクトリ構造

```
data/nouns/
├── animals.json      # 動物
├── plants.json       # 植物
├── colors.json       # 色
├── objects.json      # 物体
├── concepts.json     # 概念
├── elements.json     # 元素
├── foods.json        # 食べ物
└── phenomena.json    # 現象
```

## JSONスキーマ

各ファイルは以下の形式の名詞オブジェクトの配列です：

```json
[
  {
    "name": "魚",           // 名詞（日本語）
    "reading": "さかな",     // 読み仮名
    "english": "fish",      // 英語名
    "weight": 1.0          // 出現重み（0.0〜1.0、1.0が標準）
  }
]
```

### フィールド説明

- **name** (string, 必須): 名詞の日本語表記
- **reading** (string, 必須): ひらがなの読み仮名
- **english** (string, 必須): 英語での名称
- **weight** (number, 必須): 出現確率の重み
  - 1.0: 通常の確率
  - < 1.0: 出現しにくい（レア）
  - > 1.0: 出現しやすい（コモン）

## カテゴリ説明

### animals.json - 動物
生き物全般。魚、鳥、哺乳類、昆虫など。
- 例: 魚、猫、犬、龍、蝶

### plants.json - 植物
植物、樹木、花など。
- 例: 桜、薔薇、竹、松

### colors.json - 色
色彩、色名。
- 例: 赤、青、金、琥珀

### objects.json - 物体
人工物、道具、楽器など。
- 例: 本、剣、鏡、時計

### concepts.json - 概念
抽象的概念、自然物。
- 例: 夢、光、風、星

### elements.json - 元素
元素、属性、物質。
- 例: 火、水、鉄、金

### foods.json - 食べ物
食材、調味料、飲料。
- 例: 米、魚、味噌、茶

### phenomena.json - 現象
自然現象、時間、季節。
- 例: 朝、春、嵐、雷鳴

## GUID → 名詞マッピングルール

GUIDから名詞へのマッピングは以下の手順で行われます：

1. **GUIDのハッシュ化**
   - GUIDをSHA-256でハッシュ化
   - 32バイトのハッシュ値を得る

2. **カテゴリ決定**
   - ハッシュの最初の1バイト（0〜255）を8で割った余りでカテゴリを決定
   - 0: Animal, 1: Plant, 2: Color, 3: Object, 4: Concept, 5: Element, 6: Food, 7: Phenomenon

3. **名詞インデックス決定**
   - ハッシュの2〜5バイト目（4バイト）をu32として解釈
   - weight を考慮した重み付き抽選で名詞を選択

4. **レアリティ決定**
   - ハッシュの6〜9バイト目（4バイト）をu32として解釈
   - 確率に基づいてレアリティを決定:
     - Common: 60%
     - Rare: 30%
     - Epic: 9%
     - Legendary: 1%

5. **属性値決定**
   - ハッシュの10〜13バイト目: 興味度（interest）
   - ハッシュの14〜17バイト目: 美しさ（beauty）
   - それぞれ0.0〜1.0の範囲に正規化

## 名詞の追加方法

1. 適切なカテゴリのJSONファイルを編集
2. 新しい名詞オブジェクトを配列に追加
3. name, reading, english, weight フィールドを設定
4. レアな名詞は weight を 0.1〜0.9 に設定

例:
```json
{
  "name": "不死鳥",
  "reading": "ふしちょう",
  "english": "phoenix",
  "weight": 0.1
}
```
