# Curion - プロジェクトビジョン

## 核となる哲学

> **「VRがなくても TUIで遊べるメタバース」**
>
> **「この世で普通は手に入らないものをコレクションして、擬似的にもう一つの世界、人生を体験できること」**

---

## Curionとは何か

Curionは、単なるコレクションゲームではありません。
それは、ターミナルという制約の中で実現する、もう一つの世界です。

### メタバースの再定義

従来のメタバースは3D仮想空間やVRを前提としていますが、Curionは違います。
**テキストと記号だけで、無限の想像力を刺激する世界**を創造します。

```
┌─────────────────────────────────────┐
│ VRメタバース = 視覚的没入           │
│ Curionメタバース = 概念的没入        │
└─────────────────────────────────────┘
```

**「龍」**という文字を見たとき、
**「★★★★」**というレアリティを見たとき、
プレイヤーの心の中に、それぞれの龍が立ち上がります。

それは誰かが作った3Dモデルではなく、
**プレイヤー自身の想像力が創り出した、唯一無二の龍**です。

---

## この世で手に入らないものをコレクションする

### 物理的制約からの解放

現実世界では：
- 龍は伝説の存在
- 鳳凰は神話の生き物
- 「愛」や「美」は触れることができない
- 「時間」や「空間」は所有できない
- 「永遠」や「無限」は概念でしかない

**Curionの世界では、これらすべてがコレクション可能です。**

```
あなたのコレクション:
- ★★★★ 龍
- ★★★ 愛
- ★★ 永遠
- ★ 美
```

これは単なるデジタルデータではありません。
**あなただけの、もう一つの世界における財産**です。

### 擬似的なもう一つの人生

現実の人生では：
- 世界中を旅することは困難
- 全ての生き物に会うことは不可能
- 抽象概念を手に取ることはできない
- 異なる文化のレアアイテムを集めるには莫大な時間と金が必要

**Curionでは、これらがすべて可能になります。**

## TUIの美学

### なぜTUI（Terminal User Interface）なのか

**1. 想像力の余地**
- 3Dグラフィックは「見せすぎる」
- TUIは「示唆する」だけ
- プレイヤーの想像力が世界を完成させる

**2. アクセシビリティ**
- ハイスペックPCは不要
- VRヘッドセットも不要
- ターミナルがあれば、どこでも遊べる

**3. 詩的な美しさ**
```
最新キュリオン: ★★★★ [Legendary] 元素の 金

この一行が、無限のストーリーを語る
```

**4. レトロフューチャー**
- 80年代のテキストアドベンチャーの精神
- 現代の技術で実現する新しい体験
- 未来と過去が交差する美学

## ごった煮の世界観

### カテゴリの壁を越える

Curionの世界では、すべてが混ざり合います：

**現実と空想**
```
猫 + 龍 = ?
鳳凰 + 氷 = 氷鳳凰
```

**具象と抽象**
```
愛 + 猫 = 愛猫
美 + 料理 = 美食
正義 + 剣 = 聖剣
```

**物質と概念**
```
時間 + 空間 = 宇宙
生 + 死 = 輪廻
材料 + 火 + 愛 = 愛情料理
```

この**秩序なき秩序**、**計画された混沌**が、
Curionの世界を唯一無二にします。

## もう一つの人生

### コレクターとしての人生

現実世界でコレクターになるには：
- 多額の資金
- 広大な保管スペース
- 専門知識
- 時間と労力

**Curionでは、誰もが平等にコレクターになれます。**

### 旅人としての人生

```
日本で「桜」を獲得
中国で「龍」を獲得
ヨーロッパで「聖剣」を獲得
```

物理的に旅をすることなく、
**デジタルな旅**を通じて、世界中のレアアイテムを集める。

### 錬金術師としての人生

```
水 + 火 = 蒸気
土 + 水 = 泥
猫 + 愛 = 愛猫
```

試行錯誤を繰り返し、
誰も知らない新しい組み合わせを発見する。

**これは、もう一つの人生における研究者・探究者としての道です。**

### 商人としての人生

P2P交換システムを通じて：
- レアアイテムを交渉する
- 地域限定品をトレードする
- 信頼関係を築く

**これは、もう一つの人生における経済活動です。**

## 中毒性の本質

なぜCurionは中毒性があるのか？

### 1. **所有の喜び**
「龍」を手に入れたとき、
それはあなただけのものです。

### 2. **発見の喜び**
新しいレシピを見つけたとき、
まだ誰も見たことのないキュリオンを合成したとき、
探検家のような興奮があります。

### 3. **完全性への欲求**
図鑑のすべてを埋めたい。
全カテゴリをコンプリートしたい。
この「完全性」への渇望が、プレイを続けさせます。

### 4. **擬似的な達成感**
現実世界では達成困難なことが、
Curionの世界では可能です。

- 世界中を旅した気分
- レアアイテムを集めた満足感
- 錬金術師になった実感

**これらは「擬似的」ではありますが、脳にとっては「本物の」達成感です。**

## 文化的意義

### テキストアートの復権

2025年、ほとんどのゲームは3Dグラフィック競争に突入しています。
しかし、Curionは逆を行きます。

**「制約こそが創造性を生む」**

ファミコン時代、ドット絵の制約が独特の美学を生みました。
Curion時代、TUIの制約が新しい美学を生みます。

### グローバルな文化交流

地域限定キュリオンは、文化的アイデンティティの表現です：
- 日本の「侍」「桜」
- 中国の「龍」「麒麟」
- ヨーロッパの「騎士」「城」

これらを交換することで、
**文化的な対話**が生まれます。

#### 漢字コレクション：言語学習の革命

**「この漢字が欲しい！」**

アメリカのプレイヤー: 「"龍"という漢字、めちゃくちゃカッコいい！誰か交換して！」
日本のプレイヤー: 「"Knight"と交換しない？」

これは単なるトレードではありません。
**漢字が「美しいアート作品」「コレクタブルアイテム」として認識される瞬間**です。

```
Trade Offer:
Give: ★★★ Knight (騎士)
Want: ★★★ 龍 (Dragon)

"龍の漢字、この一文字にドラゴンの全てが込められてる！"
```

英語話者にとって、漢字は「意味不明な記号」から「欲しいアイテム」に変わります。

**学習の動機付け：**
- 「この漢字の意味は何？」→ 調べる
- 「どうやって読むの？」→ 学ぶ
- 「他にどんな漢字があるの？」→ 探求する

**逆に、日本人プレイヤーにとっても：**
- 英語圏のレア単語に興味を持つ
- スペイン語、フランス語、アラビア語などの文字に魅了される

**文字そのものが、グローバルな文化交流のツールになるのです。**

### 哲学的探求

抽象概念カテゴリは、哲学的問いを含みます：
- 「愛」と「美」を合成すると何が生まれるのか？
- 「生」と「死」の組み合わせは？
- 「光」と「闇」の調和とは？

**ゲームでありながら、思索のツールでもある。**
